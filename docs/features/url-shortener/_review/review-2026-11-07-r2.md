### N1 — [stage-1] The AC-17 slow-wake test stops at the store and has a thin timing margin — **Fix now**

- **Where:** `src/test/java/io/github/igorermolenko/trimly/link/infra/StorageTimeBudgetIT.java:44`, `:91-110`.
- **AC / contract:** AC-17; `test-plan.md:63` ("still produces the normal redirect"); R1 Resolution ("expect a normal 302").
- **Problem:** the test calls `store.page()` directly, so the visitor path (`RedirectController` → `FollowShortLink` → `LinkLookup`) is never timed through a wake. A 1100 ms wake against the 1400 ms acquire limit leaves about 300 ms for the unpause, the backend fork, auth and the init SQL, which can flake on a loaded CI runner.
- **Raised by:** both reviewers.
- **Resolution:** Fix now. Add an HTTP-level case: empty the pool, pause storage, unpause after about 1.0 s, `GET /{code}` for a stored link, and assert a 302 with the expected `Location` within 2 s.

### N2 — [stage-1] Firewall-rejected owner-API addresses get Boot's `/error` JSON, not Problem Details with a `code` — **Fix now**

- **Where:** `src/main/java/io/github/igorermolenko/trimly/redirect/api/VisitorRequestRejectedHandler.java:26`, `:33-35`; `src/test/java/io/github/igorermolenko/trimly/redirect/api/RedirectIT.java:119-125` (asserts only the status).
- **AC / contract:** `openapi.yaml:24-25` (owner-API errors are Problem Details with a stable `code`), `:406` (`Problem.required`); R3 Resolution ("400 Problem Details kept for `/api/**`").
- **Problem:** `HttpStatusRequestRejectedHandler` calls `sendError(400)`, and `BasicErrorController` renders `{timestamp,status,error,path}`. Examples: `POST /api/v1/links/ab%2Fcdef/disable`, `POST /api/v1/links/abc2345;/enable`.
- **Raised by:** both reviewers.
- **Resolution:** Fix now. Under `/api`, write `application/problem+json` 400 (`type` about:blank, `title`, `status`, `code: shared.malformed_request`) and validate it against `Problem` in `OwnerApiContractIT`.

### N3 — [stage-1] A visitor opening `GET /` gets a JSON Problem, not the plain-text sentence — **Fix now**

- **Where:** `src/main/java/io/github/igorermolenko/trimly/redirect/api/RedirectController.java:31-32` (`/{segment}` does not match an empty segment).
- **AC / contract:** AC-16b (wrong length → "Link not found."); spec §3 (visitors only ever get a redirect or a plain-text sentence).
- **Problem:** `GET /` ends in `NoResourceFoundException`, which `ProblemDetailsAdvice` renders as `application/problem+json` `shared.not_found`. No test covers it.
- **Raised by:** trace reviewer.
- **Resolution:** Fix now. Map `/` to `VisitorAnswer.Message.NOT_FOUND` (text/plain, `no-store`) and add `/` to the malformed cases in `RedirectIT`.

### N4 — [stage-1] Nothing tests that production short codes come from a secure random source — **Fix now**

- **Where:** `src/main/java/io/github/igorermolenko/trimly/link/app/LinkConfiguration.java:13-15`; `src/test/java/io/github/igorermolenko/trimly/link/domain/ShortCodeGeneratorTest.java:16` builds its own `SecureRandom`.
- **AC / contract:** AC-01; `test-plan.md:32` ("it comes from a secure random source"); feature ADR-0002.
- **Problem:** if the bean switched to `java.util.Random`, every test would still pass.
- **Raised by:** trace reviewer.
- **Resolution:** Fix now. Make the production random source observable (its own bean or a package-private factory) and assert in a `*Test` that it is a `java.security.SecureRandom`.

### N5 — [stage-1] Nothing tests that the owner credential never reaches the logs — **Fix now**

- **Where:** `src/test/java/io/github/igorermolenko/trimly/OwnerAuthDenialIT.java:44` (responses are asserted, logs are not; nothing in `src/test` uses `OutputCapture`).
- **AC / contract:** AC-18; spec §6.1 ("never written to logs"); `test-plan.md:79`.

- **Raised by:** trace reviewer.
- **Resolution:** Fix now. Add `OutputCaptureExtension` to `OwnerAuthDenialIT` and assert the captured output never contains the owner credential, for both the right and a wrong credential.
