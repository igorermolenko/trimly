# 0003 — Store links in PostgreSQL on Neon Free, accessed through Spring Data JDBC, with Flyway migrations and UUIDv7 keys

- **Status:** Accepted
- **Date:** 2026-11-01
- **Deciders:** igorermolenko (owner), with Claude during the `survey` foundation session

## Context

Links must be durable, and redirects should be fast. The budget is about $5 per month, and the Spring Boot app already takes $3.69 of it on a 512 MB Fly.io Machine (ADR-0001). The interview ruled out Render's free Postgres because it is deleted after 30 days, and Fly's managed Postgres starts at $38 per month (`docs/idea-brief.md` §6).

## Decision drivers

- Fit the remaining budget of about $1.30 per month.
- Data must persist: no expiry and no periodic wipes.
- System design is a learning goal, so use a mainstream relational database with transferable skills.
- Agent-written persistence code must be easy to review.

## Considered options

1. **PostgreSQL on Neon Free**: managed Postgres, $0 and permanent, 1 GB storage, 100 CU-hours per month; compute pauses after 5 minutes idle and wakes in a few hundred milliseconds (https://neon.com/pricing, checked 2026-11-01).
2. **SQLite on a Fly volume**: a database file on the app's own disk, about $3.84 per month in total. Only one instance can write, so it can't scale horizontally.
3. **Self-run Postgres on a second Fly Machine**: about $6–7.50 per month, over budget, and the owner would run database operations themselves.

For data access, the options were Spring Data JDBC, Spring Data JPA (Hibernate) and plain SQL through `JdbcClient`.

## Decision outcome

**Chosen:**
- **Database:** PostgreSQL on Neon Free, in the same region as the app.
- **Schema changes:** versioned SQL migrations run by Flyway (`src/main/resources/db/migration/V<n>__<description>.sql`), forward only.
- **Data access:** Spring Data JDBC, chosen over JPA because nothing happens implicitly (no lazy loading, dirty checking or N+1 queries), so agent-written code is easier to review.
- **Keys:** primary keys are UUIDv7 values generated by the app. The public short code is a separate column, designed per feature.
- **Connection settings:** come only from environment variables.

## Consequences

**Positive**
- Total hosting stays at about $3.69 per month, with durable data.
- Plain Postgres: moving to another host is a dump and restore plus a connection-string change.

**Negative**
- The first query after 5 idle minutes waits a few hundred milliseconds. A redirect cache can hide this later; that is a design decision.
- Every query crosses the network between providers, so the app and the database should be in the same region.
- Free-plan limits (1 GB, 100 CU-hours per month) cap growth. Going over them suspends compute until the next billing period.

**Neutral**
- Integration tests run against a throwaway Postgres container (Testcontainers), never against Neon.
- The Neon pricing terms were checked on 2026-11-01 and may change. Re-check before relying on them.
